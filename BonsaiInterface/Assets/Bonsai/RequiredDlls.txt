# DLLs that must be in Assets/Packages for the Bonsai workflows this project runs (the samples:
# Assets/timer-workflow.bonsai, input-test.bonsai and hooks-demo.bonsai). Checked by Installer/BonsaiDllCheck.cs.
#
# None of these are in git (Assets/Packages is gitignored), so a fresh clone gets them from a Bonsai
# install: install the packages below in Bonsai, then select Assets/Bonsai/BonsaiInstaller.asset and
# click "Consolidate packages".
#
# A missing DLL does not stop the workflow from loading. Bonsai swaps every node from that
# assembly for a proxy with the same type name and no properties, so the workflow starts but those
# nodes do nothing. The only symptom is an error like
# "Bonsai.IO.CsvWriter has no settable property FileName".
#
# When your workflow starts using another Bonsai package, add its DLL here along with anything it
# references that is not part of .NET or Unity. Versions are assembly versions (major.minor.build),
# which match the NuGet package versions for everything listed. A different version is a warning,
# not an error.
#
# <dll>                             <version>  <needed by>
